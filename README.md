# 🏮 Dotzplan Bad Honnef-Selhof
### Martinszug-Sammelaktion der Grundschule St. Martin

Herzlich willkommen zur digitalen Übersicht der Laufbezirke für das traditionelle **Dotzen (Martinszug-Sammelaktion)** der **Grundschule St. Martin** in Bad Honnef-Selhof.

Hier finden Begleitpersonen, Eltern und Lehrkräfte alle interaktiven Karten für das Smartphone sowie das druckfertige Gesamtdokument als PDF.

## 📱 Hinweise zur Nutzung

* **Am Smartphone unterwegs:**
  * Jede Karte kann direkt im mobilen Browser aufgerufen werden.
  * Oben rechts befindet sich der **Vollbild-Button** (`⛶`) für eine übersichtliche Vollbildanzeige.
  * Oben links kann mit dem **Messwerkzeug** (`📏`) bei Bedarf nachgemessen werden.
  * Durch Antippen einer farbigen Strecke öffnet sich ein Popup mit dem Straßennamen und der exakten Abschnittslänge in Metern.
* **Für den Ausdruck / Offline-Nutzung:**
  * Das [PDF-Gesamtdokument](dotzplan_selhof_gesamt.pdf) herunterladen oder ausdrucken. Jede Seite ist passgenau auf eine Schulklasse abgestimmt.
  * Auf den interaktiven HTML-Seiten befindet sich zudem oben rechts ein Button **„Drucken / Als PDF speichern“**, der eine optimierte Querformat-Druckansicht bereitstellt.
